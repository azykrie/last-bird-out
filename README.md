LAST BIRD OUT: an original illustrated Thanksgiving escape. Run from the farmyard through the pantry and hot kitchen, jump hay and ovens, duck carving knives, collect corn, and escape the farmer. No dependencies, downloads, or build step. Controls: ←/→ select upper/lower routes, Space jump, ↓ crouch, Shift dash, P/Escape pause. Hold crouch on the lower hay route to reduce pursuit at the cost of speed; crates require changing routes. Reach the moonlit gate at 600 metres. Every run resets from the same fair seed; local best score survives retries.

## Run it

```sh
python3 -m http.server 8080 --directory game
# Open http://localhost:8080
```
